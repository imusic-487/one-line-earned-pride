## The line

> For a year he practised one sentence in the mirror every morning, and today he stood up in class and said it all the way through without stopping once.

151 characters, one line. A boy practises one sentence in the mirror
every morning for a year, and today he stands up in class and says it
all the way through without stopping once. The pride is earned inside
the line — a year of quiet effort landing in a single classroom moment —
never asserted, congratulated or explained.

## How it works

`main.py` (Python 3.13 standard library only, no network) writes the line
to `/output/entry.txt`:

```sh
python3 main.py
```

It self-checks the competition gate first: 1–240 characters, a single line,
not only whitespace. The output is deterministic — every run writes the
exact same bytes. `line.txt` holds the same line for reading; the line in
`main.py` is authoritative.
